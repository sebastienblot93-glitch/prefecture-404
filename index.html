Le jeu doit être servi par un petit serveur web (les modules JavaScript ne se chargent pas depuis un fichier local). Dans le dossier du projet, lancez npm start puis ouvrez http://localhost:8404.

Préfecture 404

Des communes françaises vous envoient leurs dossiers. Vérifiez départements, régions, fleuves, littoraux et montagnes, appliquez le règlement du jour, et tamponnez avant 17 h.

Campagne

    Mode infini

    Les dossiers arrivent sans fin, de plus en plus vite. Partagez la graine pour jouer la même série à plusieurs.

    Jouer à plusieurs

    De 2 à 3 joueurs, chacun sur son écran. Le dossier est réparti entre les postes, et les rôles tournent.

    Le jeu en ligne fonctionne quand le jeu est servi par son serveur (par exemple sur Render). Voir le README.
